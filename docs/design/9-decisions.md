# Artboard 9 decisions

One ruling per row of `docs/design/9-findings.md`, in the same order. Prior-round rulings cited
below are read from `docs/CONSOLE-DECISIONS.md` as it stood at `HEAD` before the working-tree
deletion (`git show HEAD:docs/CONSOLE-DECISIONS.md`).

**A note on labels.** The four kinds this task specifies — `blocked` / `gap-fill` / `deviation` /
`matches` — don't include a bare "build it, nothing's stopping you" bucket the way the prior
round's five-kind scheme did (`reconcile` covered exactly that). Where a row needs building and
nothing blocks it or argues against it, this file uses `gap-fill` for that too, even though the
row is squarely design-backed — the alternative was inventing a fifth label this task didn't ask
for. Each such row says explicitly "unblocked build" so task 5 doesn't read it as invented UI.
